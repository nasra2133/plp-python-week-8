Personal Mini-Toolkit

Project Description

This project is a simple Python toolkit with three useful tools:

- Simple Calculator: Performs addition, subtraction, multiplication and division.
- To-Do List: Allows users to add and view tasks.
- Number Checker: Checks whether a number is positive, negative or zero.

How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python toolkit.py
